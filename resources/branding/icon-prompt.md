# TileSail app icon

Created with the built-in ImageGen tool. The original generated PNG is `tilesail-icon-master.png`; macOS asset sizes are derived using `sips`.

## Prompt

Create a single exceptionally polished macOS application icon for TileSail, a premium window tiling manager. Raster app icon, square 1024x1024 canvas. One dark midnight navy rounded-square macOS squircle occupying about 88% of canvas, centered, genuinely transparent outside the squircle. Central bold abstract sailboat mark constructed from three large clean geometric tile panels: a tall luminous porcelain-white triangular sail, a smaller turquoise-to-aqua triangular sail, and a short cyan curved trapezoid hull beneath. Clever negative-space gutters between panels subtly evoke tiled desktop windows. Elegant minimal silhouette, confident proportions, beautifully restrained dimensional bevels, soft studio highlights, subtle depth and internal shadow, no busy texture. Front view, no perspective tilt. The mark occupies about 65% of the rounded square. Sophisticated Apple-quality native desktop app aesthetic, high contrast, recognizable at 32px. No lettering, no text, no watermark, no surrounding scene, no ocean, no extra symbols, no presentation board. Deliver only the finished isolated app icon with real alpha transparency outside.
