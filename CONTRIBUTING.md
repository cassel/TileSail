# Contributing to TileSail

Open bug reports and feature requests at https://github.com/cassel/TileSail/issues.
Pull requests should target main in this repository.

For a bug, include your macOS version, TileSail version, steps to reproduce and
relevant configuration. Remove private paths and window titles from diagnostics
before publishing them. Existing `aerospace` commands also work through `tilesail`.

Run `swift test` and the relevant formatting checks before submitting a change.
Keep changes focused and preserve existing settings and upstream attribution.
