The 16 MiB frame cap applies to responses as well as requests; larger CLI output
now fails with EMSGSIZE. Protocol version, byte order, and normal framing remain
unchanged. UInt32 loads are unaligned-safe. Subscriber discard reads are capped
at 64 KiB per chunk.

The save conflict guard detects edits already on disk when save begins; it is not
a transactional lock against another process writing between check and rename.
Double-quote doubling extends previously rejected shell syntax. Existing valid
single/double-quoted backslash text remains literal. This internal language does
not perform OS shell interpolation. EOF interpretation was checked against
[Apple's NWConnection receive contract](https://developer.apple.com/documentation/network/nwconnection/receive(minimumincompletelength:maximumlength:completion:)).

## Remaining work, ordered

1. **P1: IPC client identity boundary.** `server.swift` accepts peers at predictable
   `/tmp/<bundle-id>-<username>.sock`; no explicit identity/authentication check.
   Observed active Debug socket mode was 0755. This proves the absence of an
   explicit application check, not successful access by another UID. Perform an
   isolated different-UID connection test and design private owner-only endpoint
   storage/peer enforcement with a policy for legacy clients. Supported binding
   commands can invoke configured callbacks; direct `exec-and-forget` is excluded
   from the IPC parser. Do not describe this as proven arbitrary remote shell
   execution. Add connection budgets/timeouts after defining subscription behavior.
2. **P2: Installation migration.** `install-from-sources.sh` replaces the canonical
   TileSail app and unregisters the Release source, but does not inventory/archive
   old manager apps, update an existing startup agent while preserving its config
   argument, or unregister every derived product. Implement and fixture-test that
   migration before invoking installation. No installation was attempted here.
3. **Live lifecycle acceptance.** The historical Stream Deck focus-reversion issue
   needs reproduction using the actual helpers and desktop. Unit tests and a
   build do not establish its resolution. Also validate wake/sleep, reconnect,
   display-origin swaps, and temporary absence of displays under controlled use.
4. **Release gates.** CI checks tests/Debug app/Release CLI but not the complete
   release archive/cask/native migration pipeline. Signing, notarization, and
   launch-agent integration remain separate from this audit.
