# TileSail 0.22.0 Beta 1

Universal Release build for macOS 13 and later, supporting Apple Silicon and Intel.

## Changes

- Instant layout changes, resizing and TileSail fullscreen; the layout animation engine has been removed.
- Fewer redundant Accessibility writes and workspace bar redraws.
- Fixes for scratchpad restoration cancellation, size-refusal feedback, and waits during shutdown.
- Standard **About TileSail…** panel with Cleverson Cassel's creator credits, version and project links.
- Drag-to-Applications DMG with SHA-256 checksum, source metadata, installation instructions and MIT notices.

## Installation

Quit the existing TileSail/AeroSpace, open the DMG and drag TileSail.app to Applications. Keep one window manager active. Grant Accessibility access when prompted.

This beta uses the Release bundle ID `us.cassel.tilesail`. Switching from a Debug installation can require granting Accessibility access again. Existing TOML paths and `AeroSpaceSmooth.*` preferences remain compatible. Keep the application's existing location when a startup LaunchAgent references it, or update that agent's application path while preserving its configuration argument.

This build is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch; review System Settings > Privacy & Security. Native macOS minimize/fullscreen effects remain controlled by macOS.
